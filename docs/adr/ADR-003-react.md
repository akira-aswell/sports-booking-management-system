# ADR-003 — React and TypeScript

Status: Proposed for ratification (existing design reconstructed, not a historical approval). Date recorded: 2026-11-27. Suggested owner: Vinh.

## Context
Role-based pages need reusable components and typed API interactions.

## Decision
Retain React, TypeScript, Vite and React Router.

## Alternatives considered (proposed review)
Server-rendered pages or plain JavaScript.

## Consequences / trade-offs
Requires Node build tooling or frontend Docker image; type checking does not replace runtime testing.

Review with business/technical representatives. Link relevant UC/AC and test evidence before acceptance.
