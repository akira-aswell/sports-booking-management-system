## Goal
Reserve a future slot pending owner approval.

## Preconditions
Authenticated eligible role; active court; valid free interval.

## Main flow
1. Send court ID and timezone-aware start/end.
2. Lock court and validate schedule/occupancy; calculate fee from duration.
3. Persist booking PENDING, allocation active, payment UNPAID and owner notification in one transaction.
4. Return 201; rollback on conflict.

## Alternative flows and exceptions
Use the negative scenarios in the AC table below. Invalid or unauthorized mutations must not silently succeed. For conflicts, retain the previously committed valid state. HTTP response codes follow the referenced API; exact error text is not a stable contract unless explicitly agreed.
