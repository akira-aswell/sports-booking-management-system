## Goal
Represent when a facility is open or closed.

## Preconditions
Own court or admin access.

## Main flow
1. Replace weekly opening-hour intervals.
2. Create maintenance interval; delete it when no longer needed.
3. Sprint 2 extension: reject changes invalidating existing active allocations.
