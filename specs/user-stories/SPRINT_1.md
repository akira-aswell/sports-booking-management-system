# Sprint 1 — User stories and prioritized backlog

Draft priorities: Must for core workflows; Should for optional convenience. Confirm with team before acceptance.

| Story | User story | Priority | Use case | Owner |
|---|---|---|---|---|
| US-001 | As a Visitor, I want to register account so that I can create an ordinary account. | Must | [UC-001](../use-cases/UC-001.md) | Tuấn |
| US-002 | As a Registered user, I want to authenticate and authorize so that I can sign in and access only permitted functions. | Must | [UC-002](../use-cases/UC-002.md) | Tuấn |
| US-003 | As a Visitor, I want to search and inspect courts so that I can find a suitable facility. | Must | [UC-003](../use-cases/UC-003.md) | Vinh |
| US-004 | As a Owner / Admin, I want to manage courts so that I can maintain facility information. | Must | [UC-004](../use-cases/UC-004.md) | Vũ |
| US-005 | As a Owner / Admin, I want to manage opening hours and maintenance so that I can represent when a facility is open or closed. | Must | [UC-005](../use-cases/UC-005.md) | Vũ / Hùng |
| US-006 | As a Visitor, I want to check court availability so that I can inspect usable slots before requesting a booking. | Must | [UC-006](../use-cases/UC-006.md) | Vinh / Hùng |
| US-016 | As a Admin, I want to maintain sports catalog so that I can keep selectable sports valid. | Must | [UC-016](../use-cases/UC-016.md) | Khánh / Tuấn |

Sprint 2 extends UC-005 and UC-006 with allocation-aware checks; these extensions are tested within the Sprint 2 gate. File presence is not acceptance.
